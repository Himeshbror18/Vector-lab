# Contributing to Vector Lab / IXO

Thanks for helping improve Vector Lab.

## Before changing code

1. Keep the physics model and renderer separate.
2. Make every visual parameter traceable to the simulation state.
3. Preserve SI units in the model and label displayed quantities clearly.
4. Test responsive behaviour on phone and tablet widths.
5. Do not add placeholder experiment folders until an experiment is actually implemented.

## Pull requests

- Explain the user-facing change.
- Explain any physics/model change and its assumptions.
- Include screenshots or a short recording for visual changes.
- Keep commits focused and descriptive.

## Physics changes

Numerical changes should include the relevant equation/model and, where practical, a simple sanity check against a known analytical result.
